# Отчет по лабораторной работе 07

## Найденные ошибки

1. **Пропуск строк:** В исходном коде при встрече пустой строки индекс увеличивался на 2 (`_lineIndex += 2`), из-за чего следующая за пустой строка (обычно `BEGIN`) пропускалась. Исправлено на `_lineIndex++`.
2. **Бесконечная рекурсия / неверный уровень:** Индекс не увеличивался перед вызовом `PrintTree()`, из-за чего рекурсия начиналась с той же строки `BEGIN`. Исправлено: индекс инкрементируется в начале цикла.
3. **Неверные отступы:** В `GetIndent` использовалось условие `i <= _depth`, из-за чего отступ был на один блок больше нужного. Исправлено на `i < _depth`.
4. **Отсутствие ветки `└─`:** Программа всегда рисовала `├─`. Добавлен метод `IsLastChild` с заглядыванием вперед для определения последнего элемента.
5. **Пробел в имени:** `Substring(5)` захватывал пробел. Заменено на `Substring("BEGIN ".Length)`.

## Рефакторинг

- Логика вывода отделена от построения: метод `BuildTree` теперь возвращает `List<string>`, что позволяет писать юнит-тесты без перехвата консоли.
- Глобальная переменная `_depth` удалена, глубина передается через параметр метода.
- Добавлено дополнительное задание: подсчет количества дочерних элементов `(n)`.
- `GetIndent` оптимизирован с помощью `Enumerable.Repeat`.
